# Student Grade Analyzer Using STL Algorithms and Lambda Expressions

Object Oriented Programming Using C++ - Lab Manual, Ex.No 5 (Chennai Institute of Technology).

Uses `sort`, `transform`, `find_if` and `accumulate` with lambda expressions to rank students, assign grades, find the first student above 80, and compute total and average marks.

## Build and run

```
g++ -std=c++17 main.cpp -o grade_analyzer
./grade_analyzer
```

## Output

```
Student Grade Analyzer
---------------------
Name    Mark    Grade
Kumar   91      A
Arun    85      B
Bala    72      C
Ravi    65      C

First student scoring above 80: Kumar
Total Marks: 313
Average Mark: 78.25
```
